## 技術筆記

### Cloudflare Pages 部署流程
```
本地修改 → git push → GitHub → Cloudflare Pages 自動部署（約1分鐘）
```

### 後台儲存流程
```
後台修改 → GitHub API 更新 JSON → Cloudflare Pages 自動部署
```

### 圖片上傳流程
```
選擇圖片 → Canvas 壓縮 → Base64 編碼 → GitHub API 上傳 → 即時顯示（raw URL）
```
