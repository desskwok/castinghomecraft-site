- **正式網站**: https://castinghomecraft-site.pages.dev/
- **後台管理**: https://castinghomecraft-site.pages.dev/admin.html

## 📋 功能

- ✅ 響應式設計（手機/電腦）

- ✅ 圖片分組（按房間/區域）

- ✅ GitHub 自動部署
